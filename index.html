Superprompt PRISMA 2020

Generador de instrucciones para redactar cada sección de una revisión sistemática de literatura. Complete el Bloque 0, cargue sus archivos .md de contexto, elija la sección y copie el superprompt.

Cargar Bloque 0 (.md)
Importa un archivo Markdown con líneas «Campo: valor» (p. ej., «Tema: …», «Carrera profesional: …», «P (Población): …») y rellena el formulario. Sirve para retomar un Bloque 0 guardado o el que compartió otro docente.
Copiar Bloque 0 en Markdown
Copia los datos del formulario como bloque Markdown para pegarlo en un chat con IA, en el protocolo o en un archivo .md que luego puede volver a cargar.
Limpiar campos
Vacía el Bloque 0, los archivos de contexto, los borradores y la extensión objetivo. La galería de prompts no se borra.
